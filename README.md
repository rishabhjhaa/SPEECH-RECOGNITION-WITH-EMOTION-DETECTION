# SPEECH-RECOGNITION-WITH-EMOTION-DETECTION

## College Major Project

This project was developed as a **Major Project for the Bachelor of Technology (B.Tech) degree program**.

The objective of this project is to build a real-time system that can recognize speech and detect the emotional state of the speaker using Artificial Intelligence and Machine Learning techniques.

The system captures user speech input, converts speech into text, and simultaneously detects emotions such as Happy, Sad, Angry, Neutral, etc.

---

## Project Overview

The project includes:

* Audio preprocessing
* Feature extraction using MFCC
* Machine Learning / Deep Learning models
* Flask web application
* Database integration
* Real-time prediction system

Installation Steps
Install dependencies:
pip install -r requirements.txt
Run the project:
python app.py
Open browser:
(http://127.0.0.1:5000)
